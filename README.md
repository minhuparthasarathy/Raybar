# Raybar – Solar-Powered Battery Landing Page

A responsive, multi-page product website for Raybar, a solar-powered battery concept, built using HTML, CSS, and vanilla JavaScript as part of a TezosNexusCIT club initiative.

## Overview

Raybar is a product launch website designed to present a solar-powered battery concept through a modern web experience. The project focuses on responsive layouts, product presentation, interactive elements, and the structure of a multi-page product website.

Developed collaboratively, Raybar provided an opportunity to apply core frontend development skills while building a website around a clean-energy concept.

## Features

- **Responsive Design:** Layouts designed for different screen sizes.
- **Product Landing Page:** Introduces the Raybar concept and its value proposition.
- **Multiple Pages:** Includes sections such as About Us, Add to Cart, Contact, Login, Sign Up, Prices, Reviews, and Terms & Conditions.
- **Interactive Elements:** Client-side interactions implemented using vanilla JavaScript.
- **Product Media:** Includes visual assets and video files to support the product presentation.
- **Collaborative Development:** Combines frontend development, styling, forms, and visual design contributions.

## Tech Stack

| Technology | Purpose |

## Getting Started

### Prerequisites

A modern web browser is required. No package manager or build tools are needed for the basic setup.

### Installation

Clone the repository:

```bash
git clone https://github.com/minhuparthasarathy/Raybar.git
cd Raybar
```

Open `index.html` in your browser to view the website. Keep the HTML pages, images, and video assets in their existing locations so that relative file paths continue to work.
